# Часики — учим время

Детское приложение для изучения времени — аналоговые и цифровые часы, интервалы и переводы в том же стиле, что и тренажёр умножения. Для 10 лет.

## Что внутри

- **Учить** — 4 урока: устройство часов, четверти/половина, AM/PM, интервалы
- **Прочитай время** — аналоговые часы → выбери `HH:MM` (Легко/Средне/Сложно)
- **Выставь стрелки** — дано `14:35` → выбери правильные часы
- **Сколько прошло?** — два циферблата → длительность
- **Переведи время** — часы ↔ минуты, минуты до следующего часа
- **Быстрый тест** — 10 случайных вопросов микс
- **На время** — сколько успеешь за 60/45 сек (Легко/Средне/Сложно)
- **Результаты** — звезды, серия, точность, статистика по 4 навыкам, 15 достижений, экспорт/импорт

## Дизайн

1-в-1 с тренажёром умножения: `paper #FFF8EC`, `ink #3B3660`, `sun/coral/mint/sky/grape/candy`, шрифты `Unbounded + Nunito`, `BigButton`, `Decor`, `Mascot`, `Confetti`, PWA.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite
npm run preview
npm run android:sync  # синхронизация с Android (Capacitor)
```
